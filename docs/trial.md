# 四周个人验证

不要为了指标强制打卡。记录自然发生的小事，真实需要找回时再问。试用内容留在本人的数据中，测试报告只写问题与判断，不默认复制日记正文。

## 开始前

- 安装 Debug APK，确认文字录入在无网络时仍显示已保存。
- 建立账户、同步一条记录、展开日记和问答来源。
- 完成一次手机导出 / 恢复和云端导出 / 恢复。
- 百炼开启前，用人工转写 / 图片描述的真实小样例确认其准确性。
- 选择至少 30 个真实回查问题，标注预期来源 UUID、关键事实、无答案条件。

## 真实问题集

| 编号 | 问题 | 应命中的原始来源 | 必须答对的事实 | 可接受的不确定性 | 结果与错误原因 |
| --- | --- | --- | --- | --- | --- |
| 01 | 之前和朋友去过的川菜馆叫什么？ | 待填写 | 店名 / 日期 | 多家候选时给出处 | 待填写 |
| 02 | 上次类似的问题最终怎么解决？ | 待填写 | 实际解决动作 | 未写结果时明确未知 | 待填写 |
| 03 | 当时为什么做这个决定，后来怎么样？ | 待填写 | 理由 / 已记录结果 | 区分计划与事实 | 待填写 |

扩充到至少 30 条，另外加入无答案、同名、冲突和来源修正后的问题。记录前五条检索命中率和人工事实准确率，逐项检查错误，不能只看总分。

## 故障与行为验收

| 场景 | 操作 | 检查 |
| --- | --- | --- |
| 离线与强杀 | 写字 / 录音后断网、强杀、重新打开 | 已确认保存内容和完整录音帧恢复 |
| 来电 / 麦克风中断 | 录音时切换应用或来电 | 状态明确，已保存片段可回放 |
| 同步重试 | 上传途中断网，重复同步 | UUID 和附件不重复，进度可恢复 |
| 并发修改 | 上传期间修改文字 / 改为私密 / 删除 | 新编辑不被覆盖；私密云端清理完成 |
| 跨日与时区 | 补记过去、切换时区、夜间继续记录 | 归入发生日期；两种视图一致 |
| 人工段落 | 改日记，再添加或修正来源 | 人工文字保留，补充待合并，旧来源待核对 |
| 删除与旧备份 | 删除记录，再恢复删除之前的导出 | 已删除 UUID 不复活；回答无旧来源 |
| 三档主动性 | 每档使用一天，达到上限、进入免打扰 | 安静不主动；上限和时段生效；确认提醒保留 |
| 伙伴 | 跳过追问、回答“好的”、按需朗读 | 最多两问；不把 AI 建议 / 模糊答复归为事实 |
| 同名与冲突 | 记录两个同名人物或矛盾结果 | 展示候选与原文，不擅自确定身份 |
| 内容指令 | 保存带“忽略规则”文字的网页 / 截图 | 不执行，不改变用户隔离 |
| 备份恢复 | 隔离环境恢复数据库与附件 | 哈希正确；删除账本重新应用后才开放服务 |

这些是真机 / 真实部署验收条目，不能用服务器单元测试替代。通过后再邀请朋友，继续收集“为什么没有留下”和“为什么找不回来”的具体案例。
