## 尚未完成的验收和限制

- 本机没有百炼密钥；ASR、视觉和向量是真实接口适配，但未实际调用验证。DeepSeek 模式只验证文字能力。
- 本机没有 Docker / PostgreSQL / OSS 环境；生产队列并发、pgvector 实际查询、容器启动和云端备份恢复未执行。CI 已配置 PostgreSQL 集成测试，但未运行远程 CI。
- 四周个人使用与至少 30 条真实人工标注问题待执行，见 `trial.md`。
- 人物目前按姓名线索与人工别名管理；复杂同名人物逐条身份拆分需要增强，系统仍保留待确认提示。
- 自动化旧记忆关联先结合关键词；百炼向量实际效果待验证。对很模糊且没有共同词的提问，DeepSeek 测试模式可能找不到相关来源。
- 大量历史记录的分页、检索吞吐和电量开销未压测。ZIP 恢复当前限制 100MB 解压内容 / 单附件 20MB / 5000 条目，长期大规模备份分片需要扩展。
- 原始语音保留与回放已实现；单独清理已转写录音的工具尚未实现，目前删除操作以整条记录为单位。
- 七天 Token 到期需要重新登录；同一安装绑定一个账户。当前不支持在一个安装中切换多个账户。
- 主动消息与确认提醒使用服务端收件箱 + WorkManager 本地通知，不保证准点到达。用户在免打扰内收到的消息会在允许时段或打开 App 后查看。
- 费用采用配置单价、固定费用与在途预留估算。测试脚本使用独立临时数据库，其费用需另与服务商账单对照；预算统计不代表账户实时账单。

下一步验收顺序：真机录入和故障恢复 → 百炼多模态 → PostgreSQL / OSS 恢复演练 → 真实样例质量 → 四周使用 → 朋友内测。代码完成与这些验收结果分别记录。
